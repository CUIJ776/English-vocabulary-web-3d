# 3D surface and figure sources

The game uses local 512 px color and OpenGL normal maps from the following Poly Haven assets. [Poly Haven's asset license is CC0 1.0](https://polyhaven.com/license).

| Files | Source |
| --- | --- |
| `forest-*` | [Forest Ground 04](https://polyhaven.com/a/forest_ground_04) |
| `rock-*` | [Rocky Terrain 02](https://polyhaven.com/a/rocky_terrain_02) |
| `boards-*` | [Wood Planks Grey](https://polyhaven.com/a/wood_planks_grey) |
| `pavers-*` | [Cobblestone Floor 02](https://polyhaven.com/a/cobblestone_floor_02) |

The head data in `wordwander/world-head-data.js` is cropped and triangulated from the [MakeHuman base mesh](https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/makehuman/data/3dobjs/base.obj), released under [CC0 1.0](https://www.makehumancommunity.org/about/license.html). Only the head and neck surface is included. Hair, eyes, clothes, surface colors and animation are authored for the game.
